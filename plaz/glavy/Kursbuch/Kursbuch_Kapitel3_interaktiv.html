      📖 Auf einen Blick — Grammatik

      1. Artikel: unbestimmter (ein/eine) und bestimmter Artikel (der/das/die)
      ... ein Herd → Der Herd ist alt.
      ... ein Bügeleisen → Das Bügeleisen ist kaputt.
      ... eine Waschmaschine → Die Waschmaschine ist neu.
      2. Artikel: der/das/die – ein/eine – kein/keine – mein/meine, dein/deine
      der Kuli: Das ist ein/kein/mein/dein Kuli.
      das Heft: Das ist ein/kein/mein/dein Heft.
      die Schere: Das ist eine/keine/meine/deine Schere.

      TIPP: Nomen immer mit Artikel lernen.
      3. Artikel und Personalpronomen (er/es/sie)
      Der Kuli ist sehr schön und → er funktioniert auch gut.
      Mein Fernseher ist gut. → Er ist fast neu.
      Das Handy kostet 95 Euro. → Es hat auch eine Kamera.
      Dein Handy ist super! → Es hat auch Internet.
      Die Waschmaschine ist neu. → Sie wäscht sehr gut.
      Rolf hat eine Digitalkamera. → Sie ist super.
      Die Zahlen bis eine Million
      0 null, 1 eins, 2 zwei ... 12 zwölf, 13 dreizehn ... 20 zwanzig, 21 einundzwanzig ... 100 (ein)hundert, 101 (ein)hunderteins, 113 (ein)hundertdreizehn, 221 zweihunderteinundzwanzig, 866 achthundertsechsundsechzig, 1.000 (ein)tausend, 1.113 (ein)tausendeinhundertdreizehn, 100.000 (ein)hunderttausend, 1.000.000 eine Million

      🗣️ Aussprache

      Vokale: a, e, i, o, u
      Vokal + h: zehn, wohnen (lang)
      Zwei Vokale: Tee, sieben (lang)
      Vokal + ein Konsonant: Tag, Name, hören (lang)
      Vokal + mehrere Konsonanten: Heft, Tabelle (kurz)

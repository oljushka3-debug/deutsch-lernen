📖 Auf einen Blick — Grammatik

1. Personalpronomen und Konjugation
Singular: ich trink-e, du trink-st, er/es/sie trink-t
Plural: wir trink-en, ihr trink-t, sie trink-en
Formell (Sg./Pl.): Sie trink-en
2. Verbformen
komm-en / heiß-en / sprech-en / nehm-en / antwort-en
ich: komm-e / heiß-e / sprech-e / nehm-e / antwort-e
du: komm-st / heiß-t / sprich-st / nimm-st / antwort-e-st
er/es/sie: komm-t / heiß-t / sprich-t / nimm-t / antwort-e-t

haben: hab-e, hast, hat, hab-en, hab-t, hab-en
sein: bin, bist, ist, sind, seid, sind
möcht-: möcht-e, möcht-e-st, möcht-e, möcht-en, möcht-e-t, möcht-en
3. Verbposition — Ja/Nein-Frage und Aussagesatz
Ja/Nein-Frage: (Verb) Nimmst (Verb) du Milch und Zucker?
Aussagesatz: Ich (Verb) nehme (Verb) nur Milch.
Das Verb steht in der Ja/Nein-Frage an Position 1.
